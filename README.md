# ssh-setup-tool

跨平台 SSH/Git 環境自動設定工具 | Cross-platform SSH/Git Environment Auto-setup Tool

支援 Gerrit 和 GitHub，一鍵完成開發環境配置 | Supports Gerrit and GitHub, one-click development environment configuration

## 描述 | Description

這是一個跨平台的 SSH 和 Git 環境自動設定工具，旨在簡化開發人員的環境配置流程。透過此工具，您可以快速設定 SSH 金鑰、Git 設定，並且無縫整合 Gerrit 和 GitHub 平台。

This is a cross-platform SSH and Git environment auto-setup tool designed to simplify the environment configuration process for developers. With this tool, you can quickly set up SSH keys, Git configurations, and seamlessly integrate with Gerrit and GitHub platforms.

## 功能特點 | Features

- **跨平台支援 | Cross-platform Support**: 支援 Windows、macOS 和 Linux | Supports Windows, macOS, and Linux
- **SSH 金鑰管理 | SSH Key Management**: 自動生成和管理 SSH 金鑰 | Automatically generate and manage SSH keys
- **Git 設定 | Git Configuration**: 快速設定 Git 使用者資訊 | Quick setup of Git user information
- **平台整合 | Platform Integration**: 支援 Gerrit 和 GitHub | Supports Gerrit and GitHub
- **一鍵配置 | One-click Configuration**: 簡化繁瑣的設定流程 | Simplifies complex setup processes
